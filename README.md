# 广告投放小助手 · 使用指南

> 用聊天的方式管理 NewsBreak 广告:查数据、看报表、开关投放、建新广告。
> 你只要会打字,剩下的它来做。

---

## 一、这是什么

一个连着你 NewsBreak 广告账户的聊天助手。你像跟同事说话一样提要求,它去平台上真的执行。

**它能干什么:**

| 你想干的事 | 直接这么说 |
|-----------|-----------|
| 看看有哪些广告 | 「我有哪些广告计划?」 |
| 查花了多少钱 | 「最近30天各计划花费,用表格」 |
| 比较效果 | 「哪条广告的点击率最高?」 |
| 暂停/开启 | 「把 test 计划暂停」 |
| **建新广告** | 「我想投一个新广告」 |

**它不会干什么:**
- 不会自作主张花钱——任何改动都先问过你;
- 不会瞎编数据——所有数字都是当场从 NewsBreak 查回来的;
- 目前**不能**改预算、删广告(要去后台手动操作)。

## 二、5 分钟上手

### 第 1 步:启动

在 VSCode 里打开终端(顶部菜单 Terminal → New Terminal),敲:

```bash
cd ~/workspace/my-agent
./start.sh
```

看到 `广告投放小助手启动中 → http://localhost:8100` 就成功了。
**这个终端窗口别关**,关了服务就停了。想停止就在这个窗口按 `Ctrl + C`。

### 第 2 步:搭桥(端口转发)

因为代码跑在远程开发机上、浏览器在你自己电脑上,中间要搭一座"桥":

1. VSCode 底部面板点 **「端口 / PORTS」**;
2. 点 **「添加端口 / Forward a Port」**,输入 **8100**,回车;
3. 点这一行右侧的 **小地球图标 🌐** 打开(比手输网址保险)。

### 第 3 步:开聊

页面打开后,直接点屏幕上的快捷按钮,或者自己打字:

> 我有哪些广告账户?

## 三、界面导览

```
┌──────────────────────────────────────────────┐
│ 🤖 广告投放小助手          查数据·看报表  🗑新对话 │ ← 顶栏
├──────────────────────────────────────────────┤
│  🤖 你好,我是你的广告投放小助手 👋            │
│     [我有哪些广告账户?] [最近90天各计划花费…]   │ ← 快捷提问,点一下就发
│                                              │
│                        你说的话 🧑            │ ← 你的话(蓝色,靠右)
│  🤖 助手的回答(带表格)                       │ ← 它的话(白色,靠左)
├──────────────────────────────────────────────┤
│ 📎  输入消息,回车发送(Shift+回车换行)…    ➤  │ ← 输入区
└──────────────────────────────────────────────┘
```

| 控件 | 作用 |
|------|------|
| **📎 按钮** | 上传广告素材(图片/视频)。也可以在输入框里 `Ctrl+V`(Mac `Cmd+V`)**粘贴截图**——但粘贴只支持图片,视频得用 📎 |
| **回车** | 发送。想换行按 `Shift+回车`。用中文输入法选字时按回车不会误发 |
| **🌐 EN / 中文** | 一键切换中英文:界面文字立刻换,**助手也会改用对应语言回答** |
| **🗑 新对话** | 清空当前对话重新开始(会先问你一次) |
| **快捷提问** | 开场的 4 个按钮,点一下等于替你打了那句话。发出第一条消息后它们就收起来了 |

**聊天记录会自动保存**:刷新页面、关掉标签页、明天再来,对话都还在。想从头开始就点「🗑 新对话」。

> - 记录存在你自己的浏览器里,不会上传。换浏览器/换电脑/无痕窗口/清缓存都会丢;
> - 只保留最近 200 条,超了从最旧的开始丢(超长对话建议阶段性点「🗑 新对话」重开);
> - 红色的错误提示和开场白不会存,刷新后会消失,这是正常的。

### 🌐 中英文切换

点顶栏的 **🌐 EN**(英文模式下显示 **🌐 中文**)即可切换。切换后:

- 界面所有文字、快捷提问、提示语立刻变成对应语言;
- **助手也会换语言回答**——哪怕你用中文提问,英文模式下它也用英文回复;
- 已经聊过的内容保持原样(那是历史记录,不改写),新回复才用新语言;
- 语言选择会记住,下次打开还是这个语言。

### ⚠️ 三个容易踩的坑

1. **助手思考时别重复按回车** —— 会同时发出两个请求(两份回复、两次消耗额度)。等它回完再说下一句;
2. **发送失败时,屏幕上你那句话还在,但助手其实"没听见"** —— 系统会把失败的那句从记忆里撤掉方便你重发。所以出错后请**把关键信息重新说一遍**,别以为它记得;
3. **多步向导中途出错**,最省事的做法是点「🗑 新对话」从头来,比修修补补快。

## 四、日常操作怎么说

### 查数据

```
我有哪些广告账户?
账户下有哪些广告计划?
有没有名字带 gutter 的广告?
```

### 看报表

```
最近90天各计划花了多少钱?用表格
7月份的数据怎么样?
按广告(ad)层面看看效果
哪条广告的 CTR 最高?
```

> 报表包含:**名字**、花费、**收入、ROAS**、展示、点击、转化、CPM、CPC、CPA、CTR、CVR。
> 不说时间就默认查最近 7 天(按 UTC 算,和北京时间差 8 小时)。
> 看到 **N/A** 表示平台没这项数据(比如还没有转化的计划),不等于 0。
> 报表一次最多查 **180 天**,超了会提示你缩短范围。
> 多账户时可以指定只看某个账户(单账户不用管)。

### 开启 / 暂停

```
把 test 计划暂停
再把 gutter-0729 打开
```

它会先复述要做的事 + 待办编号,**等你回一句「确认」才真的动手**。反悔就说「取消」。

## 五、建新广告(6 步向导)

说一句 **「我想投一个新广告」** 就启动。它会一步一步问,每步都告诉你「第N步/共6步」:

| 步骤 | 它问你什么 | 你要准备什么 |
|------|-----------|-------------|
| 1️⃣ 落地页 | 推广的链接 | 用户点广告后打开的那个网址 |
| 2️⃣ 预算 | 日预算还是总预算、多少钱 | **最低 $10**,新手建议 $10~$50 |
| 3️⃣ 转化事件 | 从账户里的事件挑一个 | 不懂就选它推荐的(一般是 submit form) |
| 4️⃣ 素材 | 上传图片或视频 | 点 📎 或直接粘贴图片 |
| 5️⃣ 文案 | 标题 + 描述 | **描述必须 3~90 个字符**;懒得写可以让它代拟 |
| 6️⃣ 命名 | 一个英文关键词 | 比如 `gutter`,自动命名为 `gutter-0729`(关键词-月日) |

**收集完** → 它用表格复述整单 + 待办编号 → 你回「**确认**」→ 一次性建好三层(计划 / 广告组 / 广告)。

### ⚠️ 建好之后是「暂停」状态

新广告默认全部 **OFF(暂停)**,不会花钱。这是故意的——给你一个核对的机会。

确认无误后,说一句 **「开启 gutter-0729」** 才开始真正投放。

> 新广告在 NewsBreak 后台会显示 `PENDING`(审核中),这是平台的正常流程,等审核通过才会跑。

## 六、怎么知道它真的做了(重要)

AI 有时会"嘴上说做了、其实没做"。所以我们加了**代码级的核验章**:

| 你看到 | 意思 |
|--------|------|
| 🔒 **系统核验** … 执行成功 → | ✅ 真的做成了 |
| 🔒 **系统核验** … 执行失败 → | ⚠️ **动手了但失败了**,后面跟着真实的失败原因 |
| ⚠️ **系统核验**:本轮实际上没有执行任何操作 | ❌ 它在说大话,按提示重试即可 |
| 什么章都没有 | 这轮只是聊天/查询,没有改动任何东西 |

**两句口诀:**
1. 凡是涉及改动,**没看到 🔒 就是没做成**——别只信它说的话,信这个章;
2. 看到 🔒 也**要读后半句**——「执行成功」还是「执行失败」,章本身不代表成功。

> 另外,建完广告助手会自动回平台查一遍。如果它说「回查平台未找到」或「回查失败」,
> 请自己去 NewsBreak 后台确认一眼。

## 七、安全机制(为什么它不会乱来)

```
你:"把 test 暂停"
  ↓
① 助手把动作放进「保险箱」,只登记不执行,并向你复述 + 报出待办编号
  ↓
② 你在下一条消息说「确认」
  ↓
③ 才真正执行 → 盖 🔒 章汇报结果
```

**保险丝**:登记和执行必须隔着你的一条消息。代码层强制拦截,AI 无法自问自答、自己批准自己。

**其他保护:**
- 待办存在硬盘上,服务器重启也不丢;
- 同一件事重复登记会被自动识别,不会刷屏;
- 建完广告会自动回平台查一遍,确认真的存在。

## 八、配置说明(`.env` 文件)

```bash
APP_PASSWORD=              # 访问密码,留空=不设防(见下方安全说明)
BRAIN=auto                 # 用哪个 AI 大脑,见下表
GEMINI_API_KEY=...         # Gemini 钥匙(有每日免费额度)
OPENAI_API_KEY=...         # ofox 中转 / OpenAI 官方的钥匙
OPENAI_BASE_URL=...        # 用中转站时填它的地址
OPENAI_MODEL=...           # 用中转站时指定模型名
ANTHROPIC_API_KEY=         # Claude 钥匙(可空)
NEWSBREAK_ACCESS_TOKEN=... # NewsBreak 广告平台的钥匙
```

**`BRAIN` 怎么选:**

| 值 | 行为 |
|----|------|
| `auto`(或留空) | 免费的 Gemini 优先,额度用完自动切 ofox(**推荐**) |
| `openai` | 直接用 ofox 中转(免去先撞额度墙的等待,响应更稳) |
| `claude` | ⚠️ **别用**——Claude 这条路还没接工具,切过去只能闲聊,查不了数据、也不能开关广告 |

> 只有 `openai` 和 `claude` 是特殊值,写别的(包括 `auto`、`gemini`、拼错的字)都会走默认的三级火箭。

改完 `.env` **不用重启**,下一条消息就生效。

### 🔐 访问密码(分享给别人前必设)

默认 `APP_PASSWORD` 是空的 = **谁能访问 8100 端口,谁就能操作你的真实广告账户**(包括开关投放花钱)。
自己一个人在开发机上用没问题,但只要你把端口分享出去、或部署到别的机器,**必须设密码**:

```bash
APP_PASSWORD=你自己定一个密码
```

存盘即生效(不用重启)。之后打开页面会弹浏览器登录框,**用户名随便填,密码填对即可**。

> 已同时关闭 FastAPI 自带的接口文档(`/docs`、`/openapi.json`),避免把操作说明书也暴露出去。

### 🔒 密钥安全

- `.env` 里全是真钥匙,**不要外传、不要截图、不要发群里**;
- 项目已配好 `.gitignore`,用 git 时会自动排除 `.env`;
- 钥匙分两类别搞混:`GEMINI/OPENAI/ANTHROPIC` 是给 **AI 大脑**用的,`NEWSBREAK` 是给**广告平台**用的。

## 九、出问题怎么办

| 症状 | 原因 | 解决 |
|------|------|------|
| 浏览器说「**拒绝连接**」 | 没搭桥 | 端口面板添加 8100 |
| 页面**一直转圈** | 桥断了或服务停了 | 端口面板删掉 8100 重新添加;还不行就重跑 `./start.sh` |
| 页面能开但**回复报错** | 代码或额度问题 | 看下面几行 |
| 「Gemini 免费额度暂时用完」 | 当天免费额度耗尽 | 等次日重置(北京时间下午 3~4 点),或把 `BRAIN` 改成 `openai` |
| 「素材上传失败」 | 平台按图片内容查重等 | 报错里会写真实原因;换张图或改文件名重试 |
| 助手反复让你确认 | 罕见,AI 忘了待办编号 | 说「查一下保险箱里有什么待办」,然后说「执行待办 XXXX」 |

**排障口诀**:拒绝连接=没桥 · 一直转圈=桥断了 · 页面报错=找开发

## ⚠️ 使用须知

1. **这个助手操作的是真实广告账户**,开启广告 = 真的开始花钱;
2. **建广告默认是暂停态**,核对无误再开启;
3. **认准 🔒 系统核验章**,没有章就是没执行成功;
4. **`.env` 里是真钥匙**,泄露等于把账户交给别人;
5. 目前**改预算、删除**等操作还没接入,需要去 NewsBreak 后台手动做。
