# 广告投放小助手 · 使用指南

> 用聊天的方式管理 NewsBreak 广告:查数据、看报表、开关投放、建新广告。
> 你只要会打字,剩下的它来做。

---

## 一、这是什么

一个连着你 NewsBreak 广告账户的聊天助手。你像跟同事说话一样提要求,它去平台上真的执行。

**它能干什么:**

| 你想干的事 | 直接这么说 |
|-----------|-----------|
| 看看有哪些广告 | 「我有哪些广告计划?」 |
| 查花了多少钱 | 「最近30天各计划花费,用表格」 |
| 比较效果 | 「哪条广告的点击率最高?」 |
| 暂停/开启 | 「把 test 计划暂停」 |
| **建新广告** | 「我想投一个新广告」 |
| **定时开关** | 「每天早上9点打开 gutter-0805」 |
| **看大屏 / AI 诊断** | 顶栏点 **📊 大屏** |

**它不会干什么:**
- 不会自作主张花钱——任何改动都先问过你;
- 不会瞎编数据——所有数字都是当场从 NewsBreak 查回来的;
- 目前**不能**改预算、删广告(要去后台手动操作)。

**它现在会的 22 项本领**:查组织 / 账户 / 计划 / 广告组 / 广告 / 转化事件、**推荐素材**、**图库找素材**、**查竞品广告**、**拆解创意出方案**、拉报表、
开启暂停、建广告三层、定时开关、以及配套的确认与取消。

## 二、5 分钟上手

### 第 1 步:启动

在 VSCode 里打开终端(顶部菜单 Terminal → New Terminal),敲:

```bash
cd ~/workspace/my-agent
./start.sh
```

看到 `广告投放小助手启动中 → http://localhost:18100` 就成功了。
**这个终端窗口别关**,关了服务就停了。想停止就在这个窗口按 `Ctrl + C`。

### 第 2 步:搭桥(端口转发)

因为代码跑在远程开发机上、浏览器在你自己电脑上,中间要搭一座"桥":

1. VSCode 底部面板点 **「端口 / PORTS」**;
2. 点 **「添加端口 / Forward a Port」**,输入 **18100**,回车;
3. 点这一行右侧的 **小地球图标 🌐** 打开(比手输网址保险)。

### 第 3 步:登录

第一次用要先注册一个账号(用户名 + 密码随你定)。
**聊天记录是跟着账号走的** —— 换台电脑登录同一个账号,以前问过的都还在。

### 第 4 步:选平台

登录后会先看到「你想管理哪个平台的广告?」这一页,每个平台一张卡片:

| 卡片上的标记 | 意思 | 能干嘛 |
|---|---|---|
| 🟢 **已绑定** | 账号连上了 | 点进去直接开聊 |
| 🟠 **未绑定** | 还没填 Access Token | 点进去会教你怎么绑 |
| ⚪ **敬请期待** | 这平台还没开发完 | 按钮是灰的,点不动 |

目前 **NewsBreak 已经能用**;Nextdoor、Meta 只是占位,还没接。
选好平台之后,聊天页左上角的名字会跟着变成那个平台,顶栏的 **🔄** 随时能换一个。

### 第 5 步:开聊

页面打开后,直接点屏幕上的快捷按钮,或者自己打字:

> 我有哪些广告账户?

| **🌐 EN / 中文** | 一键切换中英文:界面文字立刻换,**助手也会改用对应语言回答** |
| **✚ 新对话** | 开一个新对话。**当前这段不会丢**——自动存进左侧列表 |
| **🕵️ 按钮** | 更新竞品查询凭据(那份凭据会过期,过期时在这儿贴一份新的,立刻生效) |
| **🔄 平台** | 回到平台选择页,换一个投放平台 |
| **☰ 按钮** | 显示/隐藏左侧对话列表 |
| **快捷提问** | 开场的 4 个按钮,点一下等于替你打了那句话。发出第一条消息后它们就收起来了 |

### 🔑 登录页 / 🧩 平台选择页

进聊天页之前会经过两道:

**① 登录页** —— 第一次用点「注册一个」开账号。用户名密码自己定。
如果管理员设了邀请码(见第十节),注册时会多一栏,要填对才能开号。
**忘了密码目前只能找管理员**(见第十一节)。

**② 平台选择页** —— 选这次要管哪个平台的广告:

| 卡片标记 | 意思 | 点了会怎样 |
|---|---|---|
| 🟢 **已绑定** | 账号连上了 | 直接进聊天 |
| 🟠 **未绑定** | 还没填 Access Token | 进聊天页,弹提示教你绑 |
| ⚪ **敬请期待** | 这平台还没开发完 | 按钮是灰的,点不动 |

目前 **NewsBreak 能用**;Nextdoor、Meta 只是占位。
选好之后聊天页左上角的名字会跟着变,顶栏 **🔄** 随时能换。

> 没绑账号就进聊天的话,输入框会被**停用**并给出绑定引导——不会让你白打一大段字才发现发不出去。

### 📂 左侧对话列表(多会话)

像常见的聊天软件一样,你可以同时留着多段对话:

- 点 **✚ 新对话** → 当前这段自动存进左栏,开一段新的(**不会删掉任何东西**);
- 左栏点任意一条 → 切回那段对话继续聊;
- 鼠标移到某条上会出现 **×** → 删除那一条(会先问你一次);
- 标题自动取你说的第一句话;最多留 50 段对话,每段最多 400 条消息。

**聊天记录跟着你的账号走**,存在服务器上:刷新、关标签页、**换台电脑登录同一个账号**,对话都还在。
别人登录他自己的账号,只看得到他自己的记录。

> - 超过上限会从最旧的开始丢(超长对话建议阶段性点「✚ 新对话」重开);
> - 红色的错误提示和开场白不会存,刷新后会消失,这是正常的。

### 🔗 接入 / 切换广告账户

顶栏那个 **🔗** 按钮就是账户入口,它本身也是状态灯:

| 显示 | 含义 |
|------|------|
| 🔗 **香港友夢互娱…**(蓝色) | 已接入,显示当前正在操作的账户 |
| 🔗 **未接入账户**(橙色) | 还没连上,一眼就能看见 |

点开后:

- **还没接入** → 粘贴**你自己的** NewsBreak Access Token 就能连上
  (去哪拿:Ad Manager → Resources → API Access Tokens)。
  **每个账号各绑各的**——别人绑过不代表你能用,你绑的别人也看不到;
- **已接入** → 看到组织名和账户列表,🟢 是当前在用的,**点另一个即可切换**;
  底部「更换 Token」可以换钥匙。

> 三个安全设计:①填进去的 Token 会**先拿去验证**,通过才保存——填错了原来那把好钥匙**原封不动**;
> ②页面上只显示掩码(`7b82••••44dc`),完整值不会回传浏览器;③换 Token 会自动清空账户选择,
> 避免拿新钥匙操作旧账户。

### 🌐 中英文切换

点顶栏的 **🌐 EN**(英文模式下显示 **🌐 中文**)即可切换。切换后:

- 界面所有文字、快捷提问、提示语立刻变成对应语言;
- **助手也会换语言回答**——哪怕你用中文提问,英文模式下它也用英文回复;
- 已经聊过的内容保持原样(那是历史记录,不改写),新回复才用新语言;
- 语言选择会记住,下次打开还是这个语言。

### ⚠️ 三个容易踩的坑

1. **助手思考时别重复按回车** —— 会同时发出两个请求(两份回复、两次消耗额度)。等它回完再说下一句;
2. **发送失败时,屏幕上你那句话还在,但助手其实"没听见"** —— 系统会把失败的那句从记忆里撤掉方便你重发。所以出错后请**把关键信息重新说一遍**,别以为它记得;
3. **多步向导中途出错**,最省事的做法是点「🗑 新对话」从头来,比修修补补快。

## 四、日常操作怎么说

### 查数据

```
我有哪些广告账户?
账户下有哪些广告计划?
有没有名字带 gutter 的广告?
```

### 看报表

```
最近90天各计划花了多少钱?用表格
7月份的数据怎么样?
按广告(ad)层面看看效果
哪条广告的 CTR 最高?
```

> 报表包含:**名字**、花费、**收入、ROAS**、展示、点击、转化、CPM、CPC、CPA、CTR、CVR。
> 不说时间就默认查最近 7 天(按 UTC 算,和北京时间差 8 小时)。
> 看到 **N/A** 表示平台没这项数据(比如还没有转化的计划),不等于 0。
> 报表一次最多查 **180 天**,超了会提示你缩短范围。
> 多账户时可以指定只看某个账户(单账户不用管)。

### 开启 / 暂停

```
把 test 计划暂停
再把 gutter-0805 打开
```

它会先复述要做的事 + 待办编号,**等你回一句「确认」才真的动手**。反悔就说「取消」。

### ⚠️ 「开启」和「暂停」不对称

**广告要真跑起来,计划 / 广告组 / 广告三层必须都是开的。** 只开计划一层,
底下还关着 → **一条广告都出不去**,而你会以为在投,白等好几天。

所以你说「开启 XXX」时,它会:

1. 先看这条计划底下有哪些广告组和广告、各自开没开;
2. **只有一组一条** → 直接一起开,不啰嗦;
3. **有好几组或好几条** → 把清单列给你,问你「**全部打开,还是只打开某几个?**」
   —— 不替你决定,因为多开一条就是多花一份钱。

**暂停就简单多了**:关掉计划,底下的自然都不投了,不用一个个关。

## 五、建新广告(5 步向导)

说一句 **「我想投一个新广告」** 就启动。它会一步一步问,每步都告诉你「第N步/共5步」。

**只问你必须决定的 4 件事**,预算和文案它替你配好——但会告诉你配了什么、为什么这么配:

| 步骤 | 它问你什么 | 你要准备什么 |
|------|-----------|-------------|
| 1️⃣ 落地页 | 推广的链接 | 用户点广告后打开的那个网址 |
| 2️⃣ 转化事件 | 从账户里的事件挑一个 | 不懂就选它推荐的(一般是 submit form) |
| 3️⃣ 素材 | 推什么产品、有没有现成图 | 有就点 📎 上传;**没有就说「帮我推荐」**(先翻你自己账户,不够再去图库找) |
| 4️⃣ 落地页类型 | 认得出就不问你 | 认不出时它会问「用什么关键词命名?」|
| 5️⃣ **预算和文案** | **不问你,直接配好给你看** | 什么都不用准备,想改的时候说一句就行 |

**第 5 步它会这样说**(举例):

> 预算和文案我先给你配好了:
> · **日预算 $20** —— 平台最低 $10,但太低跑不出量、几天都攒不够数据;$20 一两天就能看出苗头。而且**建好是暂停的,你确认前一分钱不花**。
> · **用日预算不用总预算** —— 日预算随时能关,不会一次性花光。
> · **标题**:Gutter Guards Installed Fast
> · **描述**:Free quote in 60 seconds. Local crews.
> (根据你的落地页拟的,长度已卡在平台限制内)
>
> 这些是我替你配的默认值,**想改哪一项直接说**,比如「预算改成 50」或「标题换成 XXX」。

**收集完** → 它用表格复述整单 + 待办编号(**系统替你定的项会单独标出来**)→ 你回「**确认**」→ 一次性建好三层(计划 / 广告组 / 广告)。

### 🏷 名字是自动起的,按团队规范

它会**看你的落地页是做什么的**,得出一个类型词,然后三层名字自动生成。

**现有的类型**:`roof` / `gutter` / `window` / `bathroom`

- 落地页能对上其中一个 → **直接用,不啰嗦**(只告诉你一声「我按 roof 命名」)
- 一个都对不上 → **它会问你「这次用什么关键词?」** —— 不会自己瞎编一个,
  因为编出来的词会让你以后按名字筛数据时对不上号

| 层级 | 例子 | 规则 |
|---|---|---|
| 计划 | `NB-Roof-260817-01` | NB-类型-年月日-**今天这个类型的第几支** |
| 广告组 | `260817-Roof-001` | 年月日-类型-**这支计划里的第几个组** |
| 广告 | `AD-260817-Roof-001` | AD-年月日-类型-**这个组里的第几条广告** |

日期是 **年月日 6 位**(`260817` = 2026 年 8 月 17 日),按**北京时间**算(你说几号就是几号),
带上年份是为了明年同月同日不会串号。
广告比广告组多一个 `AD-` 前缀,这样你说「开启 260817-Roof-001」时,不会分不清指的是组还是广告。

序号是**查过平台上已有的名字自动往下排的**——今天已经建过 `NB-Roof-260817-01`,
下一支就是 `-02`,不会撞名,也不用你记。

> 想完全自己起名也行,直接说「计划就叫 XXX」。

### 🖼 没有素材?让它推荐

第 3 步如果你说 **「我没有图」** 或 **「帮我推荐素材」**,它会从**你自己账户投过的广告**里
挑效果最好的几个列给你看——直接显示图片,带上真实的 CTR、转化、花费:

| 编号 | 素材 | 来自 | CTR | 转化 |
|---|---|---|---|---|
| 1 | (图) | 1-NewsBreak_333_Windows | 3.34% | 1 |
| 2 | (图) | 4-NewsBreak_333_Windows | 4.18% | 0 |

说一句「用 1」就行,不用再上传。

> **为什么先推荐你自己的素材**:有真实投放数据背书,不是凭空说"这个好",
> 而且版权和平台审核都不用操心。

### 🎨 让它直接把广告图做出来

看完同行、拿到方案之后,说一句 **「按这几版做出图来」**,它会:

1. 让 AI 画一张**没有任何文字**的画面(照着方案里的「画面怎么拍」);
2. 用**代码**把标题、描述、按钮精确排版压上去;
3. 出 **1200×628** 的成品,直接传进你的素材库——说「用第2张建广告」就能接着建。

> **为什么文字要用代码压、不让 AI 一起画?**
> AI 画英文经常拼错(`Free Estimate` 画成 `Free Estimte`),一个错字就废了整张图;
> 而且它每次的字号位置都不一样,做 A/B 测试时你会分不清「效果差」是文案不行,
> 还是这次的字正好压在房子上看不清。代码排版是**确定性**的,不会错。

**这一步要花钱**(每张几分钱),所以它会**先告诉你做哪几版、大概多少钱**,
你回一句「确认」才真的生成——和开关广告一个规矩。

### 🔍 账户里没有合适的?去图库找

说一句 **「帮我找点新素材」** 或 **「找几张 roof 相关的图」**,它会去**正规授权图库**搜,
每张都告诉你**质量怎么样**和**许可证是什么**:

| 编号 | 素材 | 尺寸 | 质量 | 许可证 |
|---|---|---|---|---|
| 1 | (图) | 1920×1005 | ✅ **推荐** — 分辨率够,比例接近信息流最佳的 1.91:1 | Pexels License(可商用,无需署名) |
| 2 | (图) | 1200×1600 | ⚠️ **不建议** — 这是竖图,信息流里会被裁掉大半 | CC0(公有领域) |

说一句「用 1」,它会把那张图**转存进你的账户素材库**,然后直接接着建广告。

> **质量差的它也会列出来并说清差在哪**,不会只挑好的给你看——
> 你要的是判断依据,不是被筛过一遍的结果。

**关于版权**:它只从许可证明确**允许商业使用**的图库里找
(Pexels / Pixabay / Openverse 的 CC0 部分),搜索时就把禁止商用的过滤掉了。
每张图都附出处链接,你随时能自己去核实。

> **它仍然不会**:自己编一个图片链接、声称能生成图片、或从上面这些图库之外的地方拿图。
> 素材来源必须是能查证的。
>
> **想要更好的图**:默认只有 Openverse 能用(不要钥匙,但多是纪实照片,
> 家装维修这类品类很少)。去 [Pexels](https://www.pexels.com/api/) 免费注册一把钥匙填进 `.env`
> 的 `PEXELS_API_KEY`,就能搜到广告级的商业摄影了,一分钟的事。
>
> 三个工具都找不到时,它会如实说没有,让你自己传一张
>(建议 1200×628 以上、清晰、别放大段文字)。

### 🕵️ 看看同行在投什么(竞品广告)

说一句 **「同行都在投什么屋顶广告?」**,它会去 OpenAdLibrary 查**别人正在投的真实原生广告**
(Yahoo / Outbrain / Taboola 这些网络上的):

| 编号 | 素材 | 投放天数 | 覆盖版位 | 还在投 |
|---|---|---|---|---|
| 1 | (图) | **44 天** | 13 个 | ✅ |
| 2 | (图) | 36 天 | 17 个 | ✅ |

**「投放天数」和「覆盖版位」是这里最值钱的两个数**——一条广告能连着投一个多月、
还铺在十几个位置上,说明广告主真的在为它持续花钱。图库的图只是"好看",这个是**市场验证过的**。

它还会帮你**总结这些高效广告的共同点**:画面是实拍还是效果图、有没有真人出镜、
有没有打价格/优惠字样、文案是从痛点切入还是从优惠切入。**这比单纯给你几张图有用得多**。

> ⚠️ **这些是别人的广告素材**。直接拿来投有版权风险,平台也可能拒审。
> 你要用它也可以(说一声就转存),但助手每次都会提醒你这一点。
>
> 💡 **默认只看美国、且还在投的**——NewsBreak 是美国平台,已经停投的广告参考价值也低。
> 想看更全的可以说「不限国家」或「把停投的也算上」。

### 🧪 照着同行的套路,做一版自己的

看完同行的广告,说一句 **「照着这几条的套路,帮我做一版我们自己的」**,它会:

1. 先**拆解**你选中的几条竞品广告(至少 2 条),看懂每条的版式、画面、文字、配色、文案角度;
2. 再**归纳**出它们的共同点,并告诉你**为什么这么做有效**;
3. 最后写出 **3 版你自己的方案**——每版包含主标题、描述、画面怎么拍、版式建议。

举个例子它会怎么说:

> **共同点**(依据 3 条)
> · 文案角度:都是「痛点 + 免费报价」组合,3 条全中 —— 降低决策成本
> · 信任背书:2 条都放了资质徽章 —— 屋顶维修客单价高,需要先建立信任
>
> **第 1 版「屋顶焕新对比」**
> · 主标题:Transform Your Damaged Roof Today
> · 描述:See the difference expert restoration makes.
> · 画面怎么拍:屋顶修缮前后左右对比,左破右新,无真人,正面直拍

> ⚠️ **这一步只给文案和画面方案,不给图。** 拿到方案后你可以按「画面怎么拍」自己拍一张,
> 或者让它去图库找一张对得上的。
>
> **它不会抄同行的文案。** 方案里的文字都是重新写的,而且系统会自动查重——
> 万一某句和竞品原句太像,那一版会被打上 ⚠️ 标记提醒你换个说法。
> 竞品的品牌名、具体价格承诺(「$99 起」这类)也都会被剔掉,那些照抄会有麻烦。

### ⚠️ 建好之后是「暂停」状态

新广告默认全部 **OFF(暂停)**,不会花钱。这是故意的——给你一个核对的机会。

确认无误后,说一句 **「开启 gutter-0805」** 才开始真正投放。

> 新广告在 NewsBreak 后台会显示 `PENDING`(审核中),这是平台的正常流程,等审核通过才会跑。

## 六、定时开关广告(分时段投放)

想让广告到点自动开、到点自动关(行话叫 **dayparting,分时段投放**),直接说人话:

```
每天早上9点打开 gutter-0805
每天晚上10点暂停 gutter-0805        ← 配成一对就是分时段投放
明天上午10点半打开 test
看看我有哪些定时任务
取消那个定时任务
```

**时间一律按北京时间理解**,它会同时告诉你对应的美东时间(方便和 NewsBreak 后台的时区对照)。

> ⚠️ **定时「打开」也是三层一起开**。和手动开启一样:只定计划一层的话,到点了广告根本不会投,
> 而且**没人盯着,你可能第二天才发现一条都没跑**。所以设定时开启时,它同样会先看清底下的
> 广告组和广告,多于一个就问你要开哪些。定时「暂停」不用,关计划就够了。

设定流程和其它写操作一样:**它先复述"什么时间、对谁、做什么"+ 任务编号 → 你回「确认」→ 才排上**。

### ⚠️ 三条必须知道的规矩

1. **服务必须一直开着** —— 定时任务靠后台每 30 秒"看一次表"来触发。
   你关掉终端 / 电脑休眠,到点就不会执行;
2. **错过的任务不会补跑** —— 错过超过 15 分钟的任务只标记「已错过」,**绝不自动执行**。
   这是故意的:避免你关机一晚,第二天一开机广告全打开、无人看管地烧钱;
3. **不烧 AI 额度** —— 看表线程只是比较时间 + 直接调平台接口,全程不经过 AI。
   只有你发消息聊天时才消耗 token。

### 怎么确认它真的执行了

```
说一句:看看我的定时任务
```

会列出每个任务的**下次执行时间**和**上次执行结果**(成功 / 失败原因 / 已错过)。
任务跑过之后,你下次聊天时它也会主动告诉你结果。

> 💡 设时间**留点余量**:说"3 分钟后"这种太贴近当下的时间容易变成过去时被拒绝。
> 一次性任务必须是**将来**的时间。

### 🤖 AI 投放诊断

点「开始分析」,AI 会读取**当前时间段的真实数据**,输出四段:

1. **一句话结论** —— 整体健康度
2. **看点** —— 哪条表现好,附具体数据
3. **问题** —— 哪条在烧钱没效果,**点名到具体广告**
4. **建议怎么做** —— 按优先级排序,每条都可执行(如"暂停 xxx 广告,已花 $45 无转化")

> 实测例子:它准确指出「广告很吸引人、点击成本便宜,但**落地页抓不住客户**」——
> 2000 多人点进来几乎无人下单,并按优先级给出了止血方案。
>
> 数据太少时它会直说"数据量还不够,建议先跑够 N 天再看",不会硬编结论。

分析大约需要 20~30 秒(要读完所有数据再思考)。

### ⚠️ 两个要知道的限制

1. **趋势图最多显示 31 天** —— 这是 NewsBreak 平台的硬限制(按天取数的接口跨度不能超过 31 天)。
   选「近 90 天 / 近 180 天」时,**KPI 和明细表仍是整个周期的**,只有趋势图那一块自动缩到最近 31 天,
   页面上会有文字说明,不用担心数据对不上;
2. **AI 诊断会消耗额度** —— 每点一次分析等于问 AI 一个大问题。看数据本身不花额度,只有点分析才花。

### 🌐 语言

大屏右上角 **🌐** 可切中英文,**界面 + AI 诊断一起切**。
和聊天页共用同一个语言设置——在任一页切换,另一页打开也是那个语言。

> 切换语言后,已经生成的那份诊断不会自动改写(那是历史结果),
> 页面会提示你点「重新分析」换成新语言。

## 八、怎么知道它真的做了(重要)

AI 有时会"嘴上说做了、其实没做"。所以我们加了**代码级的核验章**:

| 你看到 | 意思 |
|--------|------|
| 🔒 **系统核验** … 执行成功 → | ✅ 真的做成了 |
| 🔒 **系统核验** … 执行失败 → | ⚠️ **动手了但失败了**,后面跟着真实的失败原因 |
| ⚠️ **系统核验**:本轮实际上没有执行任何操作 | ❌ 它在说大话,按提示重试即可 |
| 什么章都没有 | 这轮只是聊天/查询,没有改动任何东西 |

**两句口诀:**
1. 凡是涉及改动,**没看到 🔒 就是没做成**——别只信它说的话,信这个章;
2. 看到 🔒 也**要读后半句**——「执行成功」还是「执行失败」,章本身不代表成功。

> 另外,建完广告助手会自动回平台查一遍。如果它说「回查平台未找到」或「回查失败」,
> 请自己去 NewsBreak 后台确认一眼。

## 九、安全机制(为什么它不会乱来)

```
你:"把 test 暂停"
  ↓
① 助手把动作放进「保险箱」,只登记不执行,并向你复述 + 报出待办编号
  ↓
② 你在下一条消息说「确认」
  ↓
③ 才真正执行 → 盖 🔒 章汇报结果
```

**保险丝**:登记和执行必须隔着你的一条消息。代码层强制拦截,AI 无法自问自答、自己批准自己。

**其他保护:**
- 待办存在硬盘上,服务器重启也不丢;
- 同一件事重复登记会被自动识别,不会刷屏;
- 建完广告会自动回平台查一遍,确认真的存在。

### 🔐 注册邀请码(分享给别人前必设)

现在进系统要**先登录**(见第三节)。而 `APP_PASSWORD` 管的是**谁能注册新账号**:

| `APP_PASSWORD` | 效果 |
|---|---|
| 留空(默认) | **谁摸到这个地址都能注册账号**,注册完就能操作你的真实广告账户 |

自己一个人在开发机上用,留空没问题。但只要你**把端口分享出去、或部署到别的机器,必须填**:

存盘即生效(不用重启)。把这串字发给要用的同事,让他们注册时填进去。

> ⚠️ 它**不是**你的登录密码——登录密码是你注册时自己设的那个,和这里无关。

## 十一、出问题怎么办

| 症状 | 原因 | 解决 |
|------|------|------|
| 浏览器说「**拒绝连接**」 | 没搭桥 | 端口面板添加 18100 |
| 页面**一直转圈** | 桥断了或服务停了 | 端口面板删掉 18100 重新添加;还不行就重跑 `./start.sh` |
| 页面能开但**回复报错** | 代码或额度问题 | 看下面几行 |
| 「Gemini 免费额度暂时用完」 | 当天免费额度耗尽 | 等次日重置(北京时间下午 3~4 点),或把 `BRAIN` 改成 `openai` |
| 「素材上传失败」 | 平台按图片内容查重等 | 报错里会写真实原因;换张图或改文件名重试 |
| 助手反复让你确认 | 罕见,AI 忘了待办编号 | 说「查一下保险箱里有什么待办」,然后说「执行待办 XXXX」 |
| 「Google 那边服务繁忙(503)」 | 上游临时故障,不是你的问题 | 一般会自动切到 ofox;重发一次即可。老是这样就把 `BRAIN` 改成 `openai` |
| 「素材上传失败:连接中断」 | 请求没送达服务器 | 多半是桥断了 → 端口面板删掉 18100 重加;或文件太大 |
| 启动时报 `Address already in use` | 上一个实例没退干净 | 现在 `start.sh` 会自动清理并提示;仍不行就换端口:`PORT=18200 ./start.sh` |
| **回复要等 30 秒左右** | 走的是 ofox 的 Pro 模型(更聪明但更慢) | 正常现象。3 分钟内的「…」都是在等,超时才会报"未送达" |
| 定时任务"没执行" | **多半是还没到点** | 先说「看看我的定时任务」核对**下次执行时间**和**上次结果**,再下结论 |
| 打开就跳到**登录页** | 没登录 / 登录过期(30 天) | 正常现象,登录即可 |
| 注册时说**邀请码不对** | 管理员设了 `APP_PASSWORD` | 找管理员要那串字(不是你的登录密码) |
| **忘记登录密码** | 密码是加密存的,**没法找回** | 找管理员在服务器上把 `data/users.json` 里你那条删掉,然后重新注册。**注意:聊天记录会一起没了** |
| 换台电脑登录,**记录不见了** | 多半是登错账号了 | 记录是跟账号走的,确认用户名有没有输错 |
| 平台卡片是**灰的点不动** | 那个平台还没开发完 | 目前只有 NewsBreak 能用 |
| 进了聊天页但**输入框是灰的** | 这个平台还没绑账号 | 点提示里的「现在去绑定」,或顶栏 🔗 填 Access Token |

**排障口诀**:拒绝连接=没桥 · 一直转圈=桥断了 · 页面报错=找开发

> 想确认服务活没活,别 curl `/`(没登录时它返回 302 跳登录页,是**正常**的)。
> 用这条:`curl -s -o /dev/null -w "%{http_code}\n" http://localhost:18100/login` → **200 就是活着**。

## ⚠️ 使用须知

1. **这个助手操作的是真实广告账户**,开启广告 = 真的开始花钱;
2. **建广告默认是暂停态**,核对无误再开启;
3. **认准 🔒 系统核验章**,没有章就是没执行成功;
4. **`.env` 里是真钥匙**,泄露等于把账户交给别人;
5. **定时任务靠服务持续运行**:关掉服务期间不触发,错过超 15 分钟不补跑;
6. 目前**改预算、删除**等操作还没接入,需要去 NewsBreak 后台手动做。
